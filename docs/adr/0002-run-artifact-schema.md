# Run artifact: attempt-level JSONL plus manifest, not folded parquet

Every published score must link back to its evidence, so the run artifact is the harness's output contract. OpenRouter's harness (our structural reference) writes one versioned parquet per run, one row per sample×epoch with retries folded in, and writes nothing until the run completes — a crash loses everything. We decided instead on a run directory `<artifact-dir>/<runId>/` holding three files: `manifest.json` (`format_version`, `configHash` over the config snapshot, price-table ref, params, git sha, run id, date), `results.jsonl` (one line per attempt — instance id, epoch, attempt index, status, output, usage including cache tokens, cost, trace id, latency, provider response id, verification (gate, score, per-unit detail — ADR-0005) — appended as attempts complete), and `summary.json` (aggregates, rewritten at run end and on resume).

CPET is defined as total spend across all attempts ÷ effective tasks, so attempt-level rows are required data, not a nicety — folding retries into one row loses them. JSONL is append-only: a crashed run keeps its completed attempts, and `--resume-id` reopens the same directory, refuses on `configHash` mismatch, and skips completed instance ids. Parquet written as one buffer can do none of that. We kept the reference's `format_version` and reproducibility discipline in the manifest.

**Considered options**: mirror the reference exactly (one folded parquet per run) — rejected, it drops the attempt granularity CPET needs and persists nothing until completion. Attempt-level parquet — rejected for v1, since a whole-buffer write needs a stream writer to resume, for no gain at v1 scale; revisit when the dataset volume outgrows JSONL.

**Consequences**: this schema is the input contract for the Task Economics Report prototype (#8) and for the Benchmarks API (fog). Accuracy aggregation is fixed in ADR-0005 and CPET is #9's; `summary.json`'s assembler stays pluggable.
